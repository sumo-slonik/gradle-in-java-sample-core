# gradle-in-java-sample-core
To repozytorium jest laboratorium dla początkujących w Javie, które pokazuje, czym jest Gradle, jak działa i jak z niego korzystać w projektach Java.   Zawiera prosty tutorial krok po kroku oraz przykładową strukturę projektu, dzięki czemu możesz od razu zacząć budować, testować i uruchamiać aplikacje z użyciem Gradle.
